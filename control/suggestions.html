No edge is published here. This repository holds no market price, no settlement record and no settled forecast, so no win rate, yield, edge or fair price is computed anywhere. Every strategy on this site is unscored. Items that could not be confirmed against an official source are left blank and listed on Flagged for review.

Suggestions

Improve the site, improve decision making, and discover the information that is missing — with the options laid out so the best path is chosen before any change is made.

Twelve proposals, each with at least three options, the cost of each and a recommended default. This is the review board: read a row, pick an option, and the path is decided before anything is implemented.

How a decision is taken here. Selections are stored in your browser only (localStorage) and can be exported as JSON. Nothing is sent to a server and no source file is modified by clicking. To make a choice binding, record it in COORDINATION.md and in the owning data file.
