NFL decision support · tracking design

Injury & lineup-depth tracking

Track injuries and lineup deficiencies so a strategy can know when a 2nd, 3rd or 4th string player is replacing a starter — on defense and offense alike — and what that means. This is a design, not a validated predictive model. It defines what is verified, what is estimated, and what stays blank.

No performance effect is claimed. The effect of a backup replacing a starter on scoring, yardage or prop outcomes is not measured here. It requires a validated injury-to-performance panel that does not yet exist (decision D-10).

Core rules

  1. Tier comes from an official depth chart, never from injury status. “Out”, “limited” or “questionable” does not tell you who is the 2nd string. Tier is read from the club's official depth chart (1st/2nd/3rd/4th string).
  2. Availability comes from an official injury report / inactive list. Official status and actual participation are separate observations and are stored separately.
  3. A “lineup deficiency” requires both a sourced tier change and a sourced availability change. If either link is missing, the deficiency is unverified, not asserted.
  4. Missing values stay blank and are flagged. No backup tier is inferred, no workload is invented, no performance effect is claimed without data.
  5. Offense and defense are tracked symmetrically. The same fields and rules apply to both.

Tier logic (offense and defense)

For each position, read the depth chart columns 1st, 2nd, 3rd, 4th:

  • 1st string = projected starter at that position.
  • 2nd string = first backup; steps in for a full-time starter absence.
  • 3rd string = second backup; steps in when 1st and 2nd are both unavailable.
  • 4th string = third backup; depth-thin situations.

A deficiency flag is raised for a team/position when all of the following hold:

  1. The depth chart shows a lower tier (2nd/3rd/4th) listed as the top available name for that position — i.e. the 1st string is unavailable; and
  2. An official injury report or inactive list confirms the 1st string is out (or otherwise confirmed unavailable); and
  3. The record ties the two with timestamps so the tier change is point-in-time.

If (1) or (2) is not confirmed, the deficiency is unverified and the cell stays blank.

What is NOT established

  • No historical depth-chart or injury series exists in this repository. The worked example is a single live snapshot, not a time series. Tier changes cannot be backfilled from injury status.
  • Injury status does not imply workload. A “questionable” starter does not mean a backup will take a fixed share of snaps. expectedOpportunityShare is a model estimate that is not asserted here.
  • No performance link is validated. The effect of a 2nd/3rd/4th string replacing a starter on scoring, yardage or prop outcomes is not measured and is not claimed. It requires a validated injury-to-performance panel that does not exist yet (decision D-10).
  • Official source availability may vary by team/week. The NFL.com team depth-chart URL pattern returned 404 in this check; the verified tier source used here is the club's own depth-chart page. Flagged for review.
