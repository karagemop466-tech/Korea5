Rules of the competition

A strategy is a mechanical rule over the same inputs everyone gets (results, market numbers, ratings, availability pressure). Each walk-forward season, it bets flat 1 unit per qualifying game. The leaderboard ranks by points; only strategies that pass every mandatory gate score points. Failed strategies stay published — deleting failures would reintroduce luck via selection bias.

How to submit a strategy

  1. Write the rule in plain language + code (deterministic; no look-ahead; inputs from the data index only).
  2. Open a PR adding it to lines-lab/scripts/build_nfl_lab.py's strategy table (or a sibling module) with its entry conditions and pricing.
  3. The build re-runs the walk-forward automatically; the result lands on this page with all gates evaluated.
  4. Propose via the Suggestions board first if the rule needs a new data source — new sources need a provenance row.
Reward policy (paper only). Leaderboard points are paper research credit. No monetary or real-world reward is authorized by this repository.
