Correlation Values

Correlation inputs for combining bets into parlays and player-prop combinations. When legs are correlated, combining them changes the effective odds; the inputs must be disclosed before any combination is admitted to the leaderboard.

Correlation register

Each row names a bet pair and its correlation input. Values are blank because no verified joint-outcome dataset is present in this project; each row is flagged unverified.

How correlation is used

Step 1 — Disclose

Before a parlay or prop combo enters the leaderboard, every correlated leg pair is named in the correlation register. Source: none official; flagged unverified.

Step 2 — Adjust

Correlated legs are not priced as independent. The adjusted combined probability must be documented, not assumed.

Step 3 — Gate

Validation Gate 3 (correlation disclosed) must pass before the combination is leaderboard-eligible (see Strategies).

Missing information
