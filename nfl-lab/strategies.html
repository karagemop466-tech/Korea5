Line origination

Turn forecasts into prices only after the distribution is calibrated

Game markets

For each matchup, model a joint score distribution from point-in-time offense / defense / lineup features. The 50% fair spread or total threshold is the model's median covering / scoring boundary under the defined push rules; the win probability maps to a no-margin fair moneyline price. Quote uncertainty ranges as well as a central number. Do not publish a point estimate while required inputs are missing.

Features available on official NFL pages include team statistics and the game schedule.

Player markets

Estimate an opportunity distribution (snaps / routes / touches / attempts) and conditional production distribution. The model fair prop threshold is the point where over and under probabilities meet after the market's push / void definition. Use player-specific uncertainty and lineup scenarios; never substitute a season average as a line without calibration.

Official base inputs: player statistics and reported availability. Required opportunity coverage remains unverified.

Candidate first model

Start with a transparent, regularized, opponent-adjusted baseline and a simple score / usage distribution; compare it with a historical-rate baseline and a timestamp-matched market benchmark. Add features in pre-registered ablations, calibrate on training folds only, then freeze the version for walk-forward testing. Choose hyperparameters and any minimum-sample criteria from training data and a predeclared power / governance review—not by inspecting the final holdout.

Validation gates

Fail closed before calling it skill

Data / identity gate

Resolve game/player IDs, market/settlement schema, official result, odds timestamp and source provenance. Reconcile corrections. Missing critical field = reject row.

Pre-registration gate

Freeze strategy, features, test window, benchmark, metrics, exclusions, stake unit, candidate count and pass thresholds before viewing holdout results.

Leakage gate

Enforce point-in-time feature cutoff; split by time (walk-forward), group all legs by game, and keep final season / period untouched. Fit transforms on train only.

Probability gate

Report Brier / log loss and reliability calibration for probabilities, against a baseline. Include uncertainty and subgroup stability; accuracy alone is inadequate.

Edge gate

Compare against de-vigged, timestamp-matched market prices; report closing-line value only when the closing quote is observed under defined rules. Preserve pushes and voids.

Robustness gate

Use game/season-block resampling, sensitivity checks, multiple-testing correction and realistic price/availability constraints. Publish all trials, not only winners.

Prospective gate

Run frozen paper signals prospectively through a full predeclared period; capture missed/unavailable prices and line moves. No real-money deployment until independently reviewed.

Governance gate

Audit code/data versions, access, licensing, privacy, responsible-play controls and relevant jurisdictional rules; suspend on source failure or stale injury feed.

“Remove luck” is not achievable

Randomness remains in each game and bet. A defensible goal is to estimate uncertainty, prevent leakage and overfitting, compare against strong benchmarks, and demand repeatable prospective evidence. No finite record proves future profit.
