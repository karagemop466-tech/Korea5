Validation gates

A strategy earns points only if it passes every gate below. The gates are applied to 2016–2025 data that was not used to choose any parameter, except the one tuning parameter K, which was chosen on 2006–2015.

Gates

GateNameRuleSource
G0ProvenanceMarket lines come from an official or verified source with a documented method. Fails: nfldata does not name the source of spread_line / total_line.source
G1SampleAt least 300 settled bets in the 2016–2025 out-of-sample window.source
G2Edge over break-evenHit rate ≥ 52.38% and the season-block bootstrap 95% CI lower bound above 50%.
G3SignificanceExact two-sided binomial p-value below 0.05 divided by the number of strategies tested (Bonferroni).
G4ConsistencyAt least 70% of test seasons above break-even.
G5No look-aheadPredictions use only games before kickoff; ratings are stored before each game updates them.
