How to rebuild

  1. python3 scripts/nfl_lab/fetch_games.py — downloads the games file from the nfldata archive and writes the hash manifest.
  2. python3 scripts/nfl_lab/fetch_injuries.py — runs in GitHub Actions (workflow nfl-lab-injuries), because the injury mirror is only reachable from there.
  3. python3 scripts/nfl_lab/model.py — walk-forward model, backtests, gates, correlations, parlays.
  4. python3 scripts/nfl_lab/build_site.py, then python3 scripts/nfl_lab/verify.py, then build again so this page shows the latest checks.
