How missing information is discovered, not guessed

  • Coverage counting. Every feature reports how many games actually have the value. A feature present in 40% of games is treated as missing for the other 60%, never imputed.
  • Null-and-flag. When a source returns HTTP 404 or an empty array, the field is set to blank and the row is listed on the flagged page. It is not filled from memory or from another site.
  • Two independent publishers. Results are cross-checked between nflverse and ESPN. A disagreement is published as a disagreement, not resolved by picking the more convenient number.
  • Explicit gap register. Six gaps (GAP-1 … GAP-6) are enumerated on the data audit page with the exact acquisition step that would close each one.

NFL Lines Lab — every published number is generated from data fetched and hashed by the repository's own pipeline. No betting return, payout or edge is claimed anywhere: the only market data available is a single un-timestamped line snapshot, and no player-prop market exists in any reachable source.
