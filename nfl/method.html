Method

The seven rules, the five-stage pipeline, every statistical method named, and what this system deliberately is not.

The rules this system is built on

  1. Official sources only, and only these: nfl.com, the 32 official club domains, and operations.nfl.com. A value with no page behind it does not exist here.
  2. Never infer a missing value. If the official page did not publish it, the cell is blank and badged unverified. Not zero, not "likely", not "approximately".
  3. Label every computed number. Anything this system calculates carries model. Anything read straight off an official page carries official. A judgement carries judgement.
  4. Print the sample. Every estimate carries n. Estimates below the suppression floor are withheld entirely rather than published with a warning.
  5. Separate facts that are separate. Injury status is not a lineup. A depth chart is not a snap count. A touchdown count is not a points total. Each has its own column.
  6. Freeze thresholds before results. The gate thresholds carry a version and a date, and a change is logged with the note "results seen at the time".
  7. Refuse rather than fabricate. Where the data cannot support a number — no price, no per-game logs, no snap counts — the page says so in the place the number would have been.

How a value reaches this site

  1. Probe. nfl/tools/probe.py fetches each official page and counts the regex hits for the fields we need, so a parser is never written against an assumption. Findings are in nfl/research/probe.json.
  2. Ingest. nfl/tools/fetch_official.py runs in CI, parses, and writes JSON with a sourceUrl and retrieval stamp on every record, plus a fetch report listing every failure.
  3. Compute. nfl/tools/analyze_market.py derives the statistics. Fixed random seed, so every published interval is reproducible.
  4. Build. nfl/tools/build_nfl.py renders the pages from the JSON, so no number is typed by hand anywhere.
  5. Verify. nfl/tools/verify_nfl.py re-checks every row for a source link, every computed value for a MODEL badge, every blank for an UNVERIFIED badge, and every internal link.

What this system is not

  • Not betting advice, and not a claim of edge.
  • Not a backtest: there is no price history to backtest against.
  • Not a live odds service: the official NFL sources publish none.
  • Not complete: 0 failed fetches this run, 1 club depth chart unavailable, no participation data, no per-game player logs yet.

How to reproduce

python3 nfl/tools/fetch_official.py   # CI only: needs outbound network

python3 nfl/tools/build_nfl.py        # regenerate nfl/*.html
python3 nfl/tools/verify_nfl.py       # re-check links, sources and badges
