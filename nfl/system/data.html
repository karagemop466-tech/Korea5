How this runs with no manual input

  1. .github/workflows/nfl-probe.yml records what each official page actually returns, so parsers are written against real bytes.
  2. .github/workflows/nfl-data.yml fetches every dataset, writes the fetch report, and commits the result. The dev sandbox has no outbound network; the Actions runner does, which is why ingest lives in CI.
  3. nfl/tools/analyze_market.py computes every published number from those files.
  4. nfl/tools/build_nfl.py renders this site; nfl/tools/verify_nfl.py re-checks every row's source link and every badge rule.
