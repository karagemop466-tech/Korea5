The blocker on backup string order

Requirement R16 / R17 cannot be met from an official source today. The URL https://www.nfl.com/teams/<team>/depth-chart returns HTTP 404, and the official roster page lists jersey number, position, roster status, height, weight, experience and college, with no string order and no indication of who would replace whom. Rather than invent a depth chart, the Replacement column below is left blank on every row and the requirement is recorded as blocked. Suggestion SUG-05 sets out the two ways to unblock it: search the 32 clubs' own official sites for a published depth chart, or build an estimated string order from official snap counts and label it as an estimate everywhere it appears.
