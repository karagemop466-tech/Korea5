Verify

What was checked, how to reproduce it, and what this verification does not cover.

Verification rule. Every row on this site links to the official page it came from. Where an official source has not published a value the cell is left blank and the row is listed on the Flagged for Review page. Nothing is inferred and nothing is filled in.

What was checked

The checks below are re-run by strategy-strategy-lab/verify.py, which walks every generated page, extracts every table row, and fails if any row lacks a link to an official domain or if any local link is broken.

How to reproduce

1python3 strategy-strategy-lab/pipeline.py Reads the transcribed official tables, reconciles them, computes rates, correlations and the walk-forward backtest, and writes strategy-strategy-lab/data/analysis.json.

Known limits of this verification

  • Verification confirms provenance and internal consistency. It does not re-download each official page and re-assert each value; that is proposed as SUG-15.
  • The game log is one partial season. Statistical intervals are wide and are published alongside every result.
  • No market data exists, so no claim about profitability, return or closing-line value is made anywhere.
