NFL decision support · proposal register

Suggestions — review and choose a path

A dedicated section so a reviewer can read each suggestion, compare the options, and pick the best path before anything is implemented. Every suggestion serves a decision in the decision registry and, where it depends on missing data, it stays blocked until that data is resolved. Nothing here is implemented or authorized.

No strategy has been validated and no reward is authorized. This register proposes paths only. It asserts no betting edge, correlation value, ROI, or leaderboard outcome. Where an official source has not published a value, the cell is blank and the item is flagged.

How to review and choose a path

  1. Read the decision it serves. Each suggestion is tied to a decision in the decision registry. A suggestion that does not close a decision or missing information is not ready to implement.
  2. Check the dependency. If a suggestion depends on data that is not licensed/available (timestamped odds, settlement records, a historical depth-chart series), it is blocked until resolved.
  3. Choose one path per decision. Compare the options, pick one, and record the reason. Do not implement two competing paths for the same decision until one is measured.
  4. Change the status; do not delete. Statuses: proposed → in review → approved → in progress → done, or declined with a reason. “Approved” means the path is chosen, not that it is built.
  5. Re-verify before and after. Any suggestion that adds data or a model must pass the validation gates in the NFL Lines & Strategy Lab before it can feed the leaderboard.

What this register does not do

  • It does not select a data provider, book, or jurisdiction — that is decision D-01 and must be made deliberately.
  • It does not rank strategies, because no strategy has passed a validation gate.
  • It does not authorize rewards. Any reward decision waits on D-08.
  • It does not fill missing values. Where an official source has not published a value, the cell stays blank and the row is flagged on the Flagged for Review page.
