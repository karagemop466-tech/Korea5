Suggestions & Decision Review

A single place to review every proposed change, see the options, and choose the best path before anything is implemented. Nothing here is implemented automatically: each suggestion waits for an explicit decision.

How to use this page. Each row is one suggestion. Read Decision requested and the Options, then set the Status to record the chosen path. Statuses: Proposed → Under review → Approved → Implementing → Done, or Rejected with a reason. A suggestion stays Proposed until a reviewer chooses a path.

Review rules

  • No suggestion is implemented by this page. Implementation happens only after a reviewer sets a row to Approved and records the chosen option.
  • Every factual claim behind a suggestion links to an official source in the Official reference column. Where an official source cannot confirm a value, the value stays blank and the item is flagged, not guessed.
  • The official references are starting points for verification. They are not a claim that every required field, quote or depth-chart value is available there.
