Suggestions review queue

Anyone can propose a change to the site or the NFL strategy system. Nothing is implemented silently: a reviewer reads each suggestion, chooses the best path (implement / reject / block / implement later), records the decision and the reason here, and only then is work started or formally declined.

How it works. proposed = waiting for a reviewer · under review = being read and checked against sources · chosen = approved for implementation · rejected = declined, with reason · blocked = depends on missing information (see Decisions) · implemented = done and live. The Reviewer decision column is blank while the suggestion has not been decided — blank means “pending,” not “approved.”
